6. CONTACT FORM - INFO & HOW TO MAKE IT WORK
================================================================================

CURRENT STATUS:
The form currently simulates submission (shows success/error messages after 1.5s
but doesn't actually send emails). This is intentional for safety.

TO MAKE IT SEND REAL EMAILS, YOU HAVE 3 OPTIONS:

OPTION 1: EMAILJS (Easiest - No Backend Needed)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1. Sign up free at emailjs.com
2. Create service, email template, get public key
3. Install: npm install @emailjs/browser
4. Update Contact.jsx handleSubmit to use EmailJS:

    import emailjs from '@emailjs/browser';
    
    const handleSubmit = async (e) => {
      e.preventDefault();
      setIsSubmitting(true);
      try {
        await emailjs.send(
          'service_abc123',  // your service ID
          'template_abc123', // your template ID
          {
            from_name: formData.name,
            from_email: formData.email,
            message: formData.message,
            to_email: 'your@email.com'
          },
          'your_public_key'  // your public key
        );
        setSubmitStatus('success');
      } catch (error) {
        setSubmitStatus('error');
      } finally {
        setIsSubmitting(false);
      }
    };

OPTION 2: FORMSPREE (Easy - No Backend Needed)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1. Sign up free at formspree.io
2. Get your form endpoint
3. Change form in Contact.jsx:
   <form action="https://formspree.io/f/YOUR_ID" method="POST">
4. Add hidden field: <input type="hidden" name="_next" value="/" />

OPTION 3: YOUR OWN BACKEND API (Most Control)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1. Create an API endpoint (Node.js, Python, etc.)
2. Use a mail service like SendGrid, Mailgun, or Nodemailer
3. Update handleSubmit to POST to your endpoint:

    const handleSubmit = async (e) => {
      e.preventDefault();
      setIsSubmitting(true);
      try {
        const response = await fetch('/api/send-email', {
          method: 'POST',
          headers: { 'Content-Type': 'application/json' },
          body: JSON.stringify(formData)
        });
        if (response.ok) {
          setSubmitStatus('success');
        } else {
          setSubmitStatus('error');
        }
      } catch (error) {
        setSubmitStatus('error');
      } finally {
        setIsSubmitting(false);
      }
    };

4. Create app/api/send-email/route.js with your email logic
