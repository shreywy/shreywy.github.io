================================================================================
                    FORMSPREE EMAIL SETUP GUIDE
================================================================================

The contact form is now integrated with Formspree for email sending.
Follow these steps to get it working:

================================================================================
STEP 1: CREATE FORMSPREE ACCOUNT
================================================================================
1. Go to https://formspree.io
2. Click "Sign Up" (or "Get Started")
3. Sign up with your email or GitHub account (free plan)
4. Verify your email address

================================================================================
STEP 2: CREATE A NEW FORM
================================================================================
1. After logging in, click "Create" or "New Form"
2. Enter a name for your form (e.g., "Portfolio Contact Form")
3. Select the email address where you want to receive messages
   - This should be your primary email
4. Click "Create Form"
5. Copy the Form ID (it looks like: mwpejwyb)

================================================================================
STEP 3: CONFIGURE YOUR PORTFOLIO
================================================================================
1. Create a .env.local file in your project root:
   
   File: /portfolio2/.env.local
   Content:
   NEXT_PUBLIC_FORMSPREE_ID=your_form_id_here

2. Replace "your_form_id_here" with your actual Form ID from Step 2
   
   Example:
   NEXT_PUBLIC_FORMSPREE_ID=mwpejwyb

3. Save the file

================================================================================
STEP 4: RESTART YOUR DEV SERVER
================================================================================
1. Stop your dev server (Ctrl+C)
2. Run: npm run dev
3. The environment variable will be loaded

================================================================================
STEP 5: TEST THE FORM
================================================================================
1. Go to your portfolio: http://localhost:3000 (or 3001)
2. Scroll to "Get In Touch" section
3. Fill out the contact form
4. Click "Send Message"
5. You should see a success message
6. Check your email for the message!

================================================================================
TROUBLESHOOTING
================================================================================

Issue: Form submits but no email received
Solution: 
- Check that .env.local has the correct Form ID
- Verify the email in Formspree is correct
- Check spam/junk folder
- Confirm the form was created in Formspree

Issue: "Something went wrong" error message
Solution:
- Check browser console for error messages
- Verify NEXT_PUBLIC_FORMSPREE_ID is set in .env.local
- Restart dev server after changing .env.local

Issue: Need to change where emails go
Solution:
- Log into formspree.io
- Edit your form settings
- Change the recipient email address
- No code changes needed!
